# 🐕 Voer-app

Android-app om bij te houden of de honden vandaag al gevoerd zijn, met een week- en maandrapport
en per hond het gewicht en de inentingen. Alles wordt lokaal op de telefoon opgeslagen; er is geen
server of internetverbinding nodig.

De app staat in [`android/`](android/README.md). Daar lees je ook hoe je hem installeert en hoe GitHub
hem automatisch bouwt.
